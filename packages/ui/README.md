# @gunita/ui

Shared React Tailwind components and design system tokens for Gunita Kopi POS:

- **Design Tokens**: Dark green palette (`#0F2F24`), emerald action button (`#15803D`), and warm tags for low stock alerts (`#FEF3C7` / `#D97706`).
- **Core Components**:
  - `AppShell`: Application shell wrapper combining sidebar and top bar.
  - `SidebarNav`: Responsive dark green navigation sidebar.
  - `TopBar`: Header displaying current app context, user name, role, logout button, and connection badges.
  - `Button`: Primary emerald action button, secondary, outline, and danger variants.
  - `Input`: Standardized form text/number input with validation states.
  - `Select`: Dropdown selection element.
  - `Tabs`: Horizontal tab navigation bar.
  - `Dialog`: Accessible modal dialog.
  - `DataTable`: Generic tabular data display.
  - `StatusBadge`: State indicators for orders, sync status, and warm low stock alerts.
  - `StatCard`: Dashboard and analytics metric card.
